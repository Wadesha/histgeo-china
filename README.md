# 逝去的地貌 · 中国历史地理变迁图谱

一个纯静态的「历史地理变迁」图谱网站：从邹逸麟《中国历史地理概述》的核心脉络出发，为每一类环境变迁找出**今日仍可寻见的现存实例**，说明其**背后的原理**，并用地图与时间轴重构呈现。

> 学习性重构，非商业用途。原理取自邹逸麟《中国历史地理概述》（福建人民出版社，1993）上篇「自然环境的变迁」与下篇「历代社会经济环境的变迁」；现状数据来自公开权威资料（见下）。坐标为示意值，用于空间叙事，非精确测量。

## 内容结构

站点含 **10 个主题**、**44 个证据点**，每个主题由四部分组成：**原理 → 变迁时间轴 → 现存实例 → 证据点地图**。

| 2 | 江汉—洞庭：云梦泽消亡与洞庭湖 | 水系 | 城陵矶、岳阳楼、云梦泽残迹 | 三角洲推进 + 四口分流 + 围垦 → 湖泊萎缩 |

| 9 | 政区沿革：从郡县到行省 | 人文 | 平遥古城、西安/南京明城墙、北京 | 监察区演变为行政区；集权与分权博弈 |

## 本地预览

任选其一（无需构建）：

```bash
# Python
python -m http.server 8000
# 或 Node
npx serve .
```

然后浏览器打开 `http://localhost:8000`。地图底图使用 OpenStreetMap 在线瓦片，需联网。

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库，例如 `histgeo-china`。
2. 推送到 `main`：
   ```bash
   git init
   git add -A
   git commit -m "中国历史地理变迁图谱"
   git branch -M main
   git remote add origin https://github.com/<用户名>/histgeo-china.git
   git push -u origin main
   ```
3. 仓库 **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**。
4. 稍候访问 `https://<用户名>.github.io/histgeo-china/`。

## 数据来源（现状部分）

- 黄河/废黄河：黄河水利委员会、水利部《淮河水利史》、新华社《黄河故道行知录》

- 苏北海岸：水利部黄河水利委员会、地方志
- 丝路遗址：世界遗产名录、新疆文物局相关报道
- 海上丝路：泉州申遗办 / 人民网（22 处遗产点）、上海博物馆青龙镇考古资料
